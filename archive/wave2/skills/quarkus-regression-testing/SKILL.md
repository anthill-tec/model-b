# Quarkus Regression Testing

Run full suite → verify all green → ingest with JaCoCo coverage (see `crucible-report` skill).

## Environment

```bash
export PATH="$HOME/.sdkman/candidates/maven/current/bin:$HOME/.sdkman/candidates/java/current/bin:$PATH"
```

## Test Command

```bash
mvn clean test -pl backend
```

`clean` is required for regression — ensures fresh build with accurate coverage.

## Expected Outcome

- **ALL tests pass** — zero failures, zero errors
- **Test count ≥ previous** — no tests deleted
- **No skipped tests** introduced
- **JaCoCo coverage generated** at `backend/target/jacoco-report/jacoco.csv`

## What To Check

### Build Output

```
Tests run: XXXX, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

- Any failure = STOP, do not merge
- Report the total test count in your completion message

### Coverage Report

JaCoCo CSV is generated by the `jacoco-maven-plugin` during `test` phase:

```
backend/target/jacoco-report/jacoco.csv
```

Verify this file exists before attempting coverage ingest.

### Common Regression Issues

| Symptom | Likely Cause |
|---------|-------------|
| Port 8081 already in use | Another Quarkus test instance running — wait or kill it |
| MongoDB connection refused | Test MongoDB not running — check `docker ps` |
| Flaky timeout failures | Increase Awaitility timeout, don't use `Thread.sleep()` |
| `CDI ambiguous dependency` | Duplicate `@Alternative` or `@InjectMock` conflict |
| `NoSuchMethodError` at runtime | Stale compiled classes — `mvn clean` should fix |

## Ingest

Read the `crucible-report` skill → Quarkus → Regression Run section for the exact ingest commands (test results + JaCoCo coverage).

## Gate Criteria

- All tests pass — any failure = STOP, do not merge
- Coverage ingested to Crucible
- No new warnings in build output
- Report total test count in your completion message

## Prohibited

- Merging with any test failure
- Deleting or `@Disabled`-ing tests to make regression pass
- Skipping coverage ingest
